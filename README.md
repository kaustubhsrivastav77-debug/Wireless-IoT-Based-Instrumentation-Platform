# Wireless-IoT-Based-Instrumentation-Platform

Designed and developed a wireless IoT-based instrumentation platform using ESP32
microcontrollers for real-time sensor interfacing, wireless telemetry, local visualization,
and cloud-based data logging. The system comprises a sensor node and a
receiver/dashboard node communicating over LoRa, with support for multiple
communication protocols such as I²C, SPI, UART, ADC, PWM, and GPIO. Sensor data
will be displayed locally and uploaded to MQTT, enabling remote
monitoring, alert generation, and hands-on learning of embedded systems, wireless
communication, and IoT technologies.
